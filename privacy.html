Privacy Policy

Last updated: October 28, 2026

auto-uploader ("the app") is a personal tool used by its owner to upload the owner's own videos to the owner's own YouTube channel.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Information handled through YouTube is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

Data the app accesses

With the account owner's permission (Google OAuth), the app uploads video files and sets video metadata (title, description, category, visibility) on the owner's channel, and reads the name of the authorized channel to show where videos will be uploaded. It does not read, collect or store personal data of any other user.

How data is used, stored and shared

The OAuth token is stored only in the owner's private environment and is used only to upload the owner's videos. No YouTube API data is sold, shared with or disclosed to third parties. The app does not use cookies and does not place any tracking on users' devices.

Data deletion and revoking access

The app does not keep copies of YouTube API data. The stored OAuth token can be deleted at any time by deleting the token file from the owner's environment. Access can also be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the token stops working and no further data is accessed.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.

Contact

Questions about this policy can be submitted through this project's GitHub repository.
