auto-uploader

This app uses YouTube API Services.

auto-uploader is a personal tool that uploads videos created by its owner to the owner's own YouTube channel.

  • It is used only by the owner of this project, for the owner's own channel.
  • It uploads videos and sets their title, description and visibility through the YouTube Data API.
  • It does not access, collect or share data from other users.

auto-uploader は、作成者が自分で作った動画を、作成者自身の YouTube チャンネルにアップロードするための個人用ツールです。ほかのユーザーのデータを集めたり、第三者に渡したりすることはありません。
